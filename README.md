# Gerador de Placas de Preço 🛒
Aplicativo do tipo PWA que funciona **offline** e pode ser instalado no celular, tablet ou computador, sem precisar de internet para usar depois de salvo.

## 📋 O que ele faz?
- Cria placas de preço com formatação organizada
- Funciona 100% sem conexão com a internet
- Pode ser instalado como um aplicativo nativo
- Roda direto no navegador, sem instalação complexa

## 📂 Estrutura do projeto
- `index.html`: Tela principal e todo o funcionamento do app
- `manifest.webmanifest`: Configurações para instalação como app
- `sw.js`: Script que garante o funcionamento offline
- `icons/`: Pasta com todos os ícones do aplicativo

## 🚀 Como usar
1. Acesse o link do app
2. Preencha os dados dos produtos
3. Gere e imprima ou salve as placas
4. Instale o app para usar sem internet

## 💡 Observação
Esse projeto foi desenvolvido para ser simples, rápido e leve, ideal para uso em estabelecimentos comerciais.
